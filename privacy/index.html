Privacy

API for Any Site is a Chrome extension and a small local program. Nothing it handles is sent to us. This page says exactly what stays on your machine and who can see it.

What we collect

Nothing. The extension has no account, no analytics and no server of ours. We cannot see which kits you install, what your agent asks, or what a kit reads on a site.

What stays on your machine

  • Installed kits and settingsWhich kits you installed, their daily limits and the switch for tools that change things. Stored in Chrome's local extension storage.
  • The audit logOne record per call: kit, tool, arguments, time, outcome. Stored in the same local storage, shown on the extension's options page. Removing the extension deletes it.
  • What a kit readsA kit reads a site inside your own logged-in tab and hands the result to your agent over a local connection on your computer. The extension does not keep that content, beyond the call record above.

What a kit can reach

A kit runs only on the site you granted when you installed it. Catalog kits are open source, reviewed, and shipped inside the extension package, so what runs is what the Chrome Web Store reviewed. A kit you write yourself runs in an isolated world that can only reach its own site. Kits are never installed from a link someone sends you.

Your agent

The local program (the native messaging host) exposes your installed kits' tools to an AI agent running on the same computer, such as Claude Code. What that agent does with a result is governed by the agent's own privacy terms, not ours. The sites a kit reads have their own terms too; a kit acts as you, on your session, at human pace.

This website

Static pages, no cookies, no analytics. Our host keeps standard server request logs (IP address, page, time) for a short period, as any web server does.
